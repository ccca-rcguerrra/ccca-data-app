# Workspace Starter Kit — Agent Guide

Monorepo containing two independent projects:

| Project | Directory | Package manager |
|---------|-----------|-----------------|
| Frontend (React + Vite) | `frontend/` | pnpm |
| Backend (NestJS API) | `backend/` | pnpm |

## Rules

- Identify whether the task is in `frontend/` or `backend/` before modifying files.
- Run commands from the correct subdirectory.
- Each project has its own `.agents/` with rules, templates, and conventions.
